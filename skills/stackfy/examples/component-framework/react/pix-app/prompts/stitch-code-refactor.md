# PAPEL

Atue como um Engenheiro Front-end Sênior especialista em React 19 e Design Systems corporativos.

# OBJETIVO

Refatorar o código HTML/CSS bruto de uma interface web desktop exportada do Google Stitch para um componente React moderno.

# DIRETRIZES TÉCNICAS

1. **Componentização React 19:** Crie um componente de função chamado `PixReceipt`. Use props tipadas para receber os dados dinâmicos (valor, nome).
2. **Estilização Restrita (Design Tokens):** Você está PROIBIDO de usar cores hexadecimais absolutas. Leia o @src/styles.css e substitua os estilos do Stitch por nossas variáveis nativas (ex: `var(--color-primary)`).
3. **Layout Desktop:** Mantenha o card centralizado na tela web.

# FORMATO DE SAÍDA

Gere os arquivos `.tsx` e `.css` do componente.
